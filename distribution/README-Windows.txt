星露谷纯壁纸版 · Windows 宿主
桌面版制作 zhouyang

把之前便携包的 game 文件夹放在「启动星露谷纯壁纸版.exe」旁边，然后双击启动。这个包可以替换旧版的宿主程序和 DLL。覆盖之前请先保存游戏并退出。

新安装可以下载同一网页移植版本的资源压缩包。解压后，将包含 index.html、Content.tar.count 和 _framework 文件夹的目录改名为 game，放到启动器旁边。
https://codeload.github.com/degloved-net/stardew-wasm/zip/a664842611f09771f9155b9718046649bcaded33

需要 64 位 Windows 和 WebView2 Runtime。系统托盘提供「设为常用壁纸」「开机自启动」和显示器选择。Wallpaper Engine 用户可使用同目录的本地项目。
